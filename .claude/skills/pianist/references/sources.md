# Sources: what was taken from each reference, and what was rejected

## Primary visual reference: New York Philharmonic, "Gustavo" (nyphil.org/discover/gustavo)

The build environment's network policy blocked `nyphil.org`, so the page could not be loaded live. The direction below comes from search results about the page, the NY Phil's published identity (2022 Ogilvy rebrand: black and white with one blue accent, a square typographic logo, Optimo *Plain* paired with F37 *Drago*), and the Dudamel inaugural-season campaign ("Welcome Gustavo", 2026–27). **Inspired by, not copied:** no NY Phil fonts, logo, blue or layouts are reused.

| NY Phil trait | How Srinijakara uses it |
|---|---|
| Monochrome identity with one functional accent | Ink/ivory system with one velvet accent (theirs is blue; ours is concert-hall velvet) |
| The artist's name as campaign headline ("Gustavo") | The wordmark SRINIJAKARA *is* the H1 |
| Large, art-directed, full-bleed portraits of the conductor in performance | Full-bleed, low-key, warm-monochrome portraits; one person, one moment |
| Season/concert listings tightly linked to tickets | Concert row as the signature component; Tickets is the primary action |
| Institutional calm, confident tone | Programme-style copy: facts, works, halls, dates |

## Synthesis
- **Palette:** monochrome lacquer/ivory (Instrument, A24, Bareis), warmed (Miranda, Suno, Ayaka), one action accent (Telepathic, Spotify, NY Phil), with brass ornament reserved for dark stages.
- **Type:** single condensed display face at poster scale (DICE/Foggy, A24), one weight (Instrument, Bareis), hierarchy by size and tracking.
- **Shape:** two-shape system (Instrument), with the card radius set to 0 (A24, Bareis, Ableton).
- **Rhythm:** full-bleed binary bands with 96–192px screens (A24, Instrument, Transform).
- **Metadata:** parenthesised opus tags (Ayaka, Instrument).
